## 🚀 Featured Projects

<details>
<summary><b>🧠 XAI for Early Depression Identification from Reddit Text Data</b></summary>
<br/>

Explainable ML system that detects signs of depression in Reddit posts using TF-IDF and classical classifiers, with **LIME** generating word-level explanations for every prediction rather than acting as a black box. The final calibrated SVM model achieves **0.99 AUC** with a data-driven decision threshold — and the project explicitly documents catching and fixing a data-leakage bug during calibration.

| Aspect | Details |
|---|---|
| **Stack** | Python, scikit-learn, TF-IDF, LIME, Pandas, Matplotlib |
| **Scale** | 7,731 labeled Reddit posts |
| **Performance** | 0.99 AUC (calibrated SVM), F1 = 0.9602 |
| **Security** | N/A — academic research prototype |
| **Impact** | Demonstrates explainable, calibrated, non-black-box ML for a sensitive real-world use case |
| **Repository** | [depression-detection-xai](https://github.com/AbdullahButt18/depression-detection-xai) |

This project stands out for going beyond accuracy: it applies isotonic calibration purely on held-out folds to avoid leakage, selects its decision threshold via precision-recall analysis instead of a default 0.5, and uses LIME to surface which specific words drove each prediction — making the system interpretable to non-technical and clinical readers alike.

</details>
